# thesis

Undergrad cogsci thesis on stock-flow dynamics in the ultimate frisbee 4-line drill.

Model file is `frisbee.nlogox` and can be run inside NetLogo. You can download NetLogo [here](https://www.netlogo.org/downloads/mac/).

Code and data for analyzing the recordings of people executing the drill are found in `field_recordings`. Analysis must be run through that file.
